Open a .dna or GenBank file online

Drop a sequence file here and the page reads it and shows what is inside: the name the file carries, its length, whether it is circular, every feature with its coordinates, and the plasmid map drawn from them. The file is read in your browser. It is not uploaded anywhere.

    What this page can and cannot do

    It reads and shows. It does not edit: there is no way here to change a base, add a feature or save the file back. The two buttons on the map write the same sequence out again as GenBank or FASTA, with the features the file already had.

    Only the first sequence in a file is shown. A GenBank or FASTA file can hold several records, and the page says so when yours does.

    Sequencing traces are not supported here. A .ab1 or .scf file holds four channels of fluorescence per base, which needs a chromatogram rather than a map, so the page turns those away and the PlasmidLab app opens them instead.

    Your file is read with the browser's own file reader and stays in the page. Nothing is uploaded, and there is no account to make. You can check this: open the page, turn off your network, and it still works.

    Which files it opens

    The readers are the same code the PlasmidLab app uses, so a file that opens here opens there, with the same features at the same coordinates.

    • .dna, the SnapGene® format: the binary packets, the feature and primer XML, the notes.
    • GenBank (.gb, .gbk, .genbank), including the join() and complement() locations that a feature in several pieces needs.
    • EMBL (.embl), read through the same GenBank parser.
    • FASTA (.fa, .fasta), which carries a sequence and a name but no features.
    • A .seq or .txt file of plain bases, with or without a FASTA header.

    How the map is drawn

    A circular sequence gets a circle and a linear one gets a bar, with position 1 at the top of the circle or at the left of the bar. Each feature is drawn where its coordinates put it, and features that overlap move to an inner ring or a lower row so that one does not hide another. A feature shorter than about half a percent of the sequence is drawn at that minimum width, or it would be thinner than a line. Names are placed next to their features and a name is left out when there is no room for it without landing on top of another; the table underneath always has all of them.
