How to View a Plasmid Map from a GenBank or .dna File

A plasmid map shows the layout of a DNA construct at a glance. In PlasmidLab, open a GenBank or .dna file and inspect the map alongside the sequence.

View your map

  1. Open the file with File > Open, or drop it onto the app window. See the file-opening guide if you need help.
  2. Choose View > Map. PlasmidLab displays circular and linear maps according to the document's topology.
  3. Inspect the annotated features, restriction enzyme sites and primer positions. Select a region on the map to examine a specific part of the sequence.

Check the sequence behind the map

Switch to sequence view to inspect the bases and annotations in more detail. A map is a representation of the file: check that the sequence, features and topology are correct, particularly after importing a file.

Export a map image

Choose File > Export > Map Image… to export an image, or use Edit > Copy Map as Image to copy it. The editor and map tools work without the AI agent.

What a plasmid map shows

The ring is the plasmid, drawn to scale, with its length in base pairs in the middle and the numbering running from base 1. On a circular plasmid, base 1 is wherever the file says it is, so two files of the same plasmid can be numbered differently.

Each arrow is an annotated feature, and the way it points is the strand it reads on. Four of them carry most of the information:

  • The origin of replication decides whether the plasmid is kept at a few copies per cell or a few hundred.
  • The selection marker, such as AmpR or KanR, is the antibiotic the transformation is plated on.
  • The promoter is where transcription starts, so a gene only expresses if it sits behind one and points the same way.
  • The cloning site is the run of restriction sites an insert goes into.

Enzyme names around the outside are cut sites. A map usually shows only the enzymes that cut once, because those are the ones you can cut with and still get one piece of vector back.

Where the drawing comes from

Nothing on the map is stored as a picture. It is drawn from the sequence file each time: the features and their locations come from the file’s annotations, the cut sites are found by searching the sequence for each enzyme’s recognition site, and whether the plasmid is drawn as a ring or a line comes from the topology recorded in the file. A FASTA file holds only the sequence, so a map made from one has no features until you add or detect them.
