How to Open .dna and GenBank Files on Mac or Windows

A .dna file is binary, so a text editor shows nothing useful and renaming it does not help: it needs a program that reads the format. There are two ways, and one of them installs nothing.

Just need to look at it? Drop the file on the file opener and the page prints the name, the length, whether it is circular, every feature and the map, without installing anything and without uploading the file. To edit it, or to design a cloning on it, use the app below.

Open a sequence file

  1. Install PlasmidLab from the Mac or Windows download and open the app.
  2. Choose File > Open and select your file, or drag the file onto the app window. You can open multiple files.
  3. Use View > Map to inspect the plasmid map, then switch to the sequence view to check individual bases and annotations.

PlasmidLab reads and writes .dna, GenBank and FASTA files. If a GenBank file contains multiple records, each record opens in its own tab. Sequencing traces in .ab1 and .scf can also be opened.

To look inside a file without installing anything, the file viewer reads the same formats in a browser page and shows the length, the topology, the features and the map.

Save and check your work

After editing, save your document in the format you need. Check the sequence, features and circular or linear topology after importing or converting a file, especially before using it for a cloning design.

What each format holds

Sequence files differ in how much they carry besides the bases, and that decides what survives a conversion.

  • .dna is SnapGene®’s own format. It is binary, so a text editor shows nothing useful, and it holds the sequence, the features, the primers and the topology.
  • GenBank (.gb, .gbk, .gbff) is plain text and holds the same kinds of information: the sequence, the annotated features with their locations, and whether the molecule is circular or linear, written on the LOCUS line. The GenBank guide reads one line by line.
  • EMBL (.embl) is the European equivalent of GenBank, with the same content in a different layout.
  • FASTA (.fa, .fasta, .fna) is one header line and the bases. There are no features and no topology, so a plasmid saved as FASTA loses its annotations and opens as a linear sequence until you set it back.
  • .ab1 and .scf are sequencing traces: the chromatogram and the base calls from one read, not a construct.

So converting toward FASTA loses information and cannot be undone by converting back. Keep the annotated file, and export FASTA only for a program that needs it.

If a file will not open

Check that the file contains a supported sequence format, rather than relying on the extension alone. If the app reports an unrecognized format, try obtaining a fresh export from the source program. For help, open an issue without sharing confidential sequences.

Privacy: The editor works offline. If you use the AI agent, review the privacy information before sending sequences.
