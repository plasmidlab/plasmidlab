Questions

How do I open a .dna file without SnapGene®?

Install PlasmidLab, then choose File > Open or drop the .dna file on the window. The sequence, map and features open, ready to edit. The file-opening guide walks through it.

Is PlasmidLab free?

Yes. The app is free to download and use. The AI agent includes 10 free runs per account; after that it uses your own Claude, Codex or Grok subscription or API key.

Does it run on Mac and Windows?

Yes. The Mac app runs on Apple silicon and Intel and is signed and notarized by Apple. There is also a Windows installer.

Do my files stay on my computer?

Yes. Files open from and save to your computer, and the editor and cloning tools work offline. Sequences leave your computer only when you use the AI agent or start an online search yourself, such as NCBI BLAST (Analyze > Search NCBI). The agent sends them only to the provider you chose; the free trial goes through PlasmidLab's relay to Anthropic. See the privacy page.
