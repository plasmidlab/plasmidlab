The agent

Say what you want built. The agent designs it with the app's own tools.

How it works

  1. 1Describe the constructType it in the panel in your own words: the insert, the vector, where it goes, what must stay unchanged.
  2. 2The agent designs it with the app's toolsIt runs real digests, PCRs and assemblies on the sequences you have open, not a generic recipe, and writes the plan in the chat.
  3. 3The walkthrough playsAn animated bench walkthrough of that exact design plays in the app: digest, fragments, assembly, product, one step at a time.

Works with the Claude Code, Codex or Grok CLI you already use, or an API key of your own. The editor and every cloning tool work without any of them.

Every enzyme, size and overhang in the plan
comes from your sequences, not a recipe.

Questions

Before you start.

The editor and every cloning tool work on their own. Connect an AI provider when you want the agent to design with you.

Do I need an internet connection?

The editor and cloning tools work offline. The AI agent and imports from NCBI or UniProt need an internet connection.

Which AI do I need?

Use the Claude Code, Codex or Grok CLI you already have, or an API key of your own. You can use the editor and all cloning tools without connecting any AI provider.

Can I open my existing .dna files?

Yes. PlasmidLab reads and writes .dna, GenBank and FASTA. Open a file from the File menu or drop it on the app window.

Does it run on Intel and Apple silicon Macs?

Yes. PlasmidLab supports both Intel and Apple silicon Macs, as well as Windows.

Does the agent send my sequences anywhere?

Only to the AI provider you chose, and only when you ask the agent something.

Where do I send a bug or a suggestion?

Email hello@plasmidlab.com, or report a problem or suggest a feature.
