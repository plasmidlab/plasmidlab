Questions

Does it need an internet connection?

No. The editor and the cloning tools work offline. You need a connection only for the AI agent and for importing from NCBI or UniProt.

Which AI do I need?

None for the editor or the cloning tools. For the agent, use the Claude Code, Codex or Grok command line tool you already have, or an API key of your own.

Does the agent send my sequences anywhere?

Only to the AI provider you chose, and only when you ask it something.

Can I open my existing .dna files?

Yes. PlasmidLab reads and writes .dna, GenBank and FASTA, and opens .ab1 and .scf traces. Use File > Open or drop the file on the window.

Mac with Intel or Apple silicon?

Both. There is a Windows version too.
