Before you get started

A few things you might be wondering.

And if your question isn’t here, we’d like to hear it.

Can I open my existing .dna files?

Yes. PlasmidLab reads and writes .dna, GenBank and FASTA files. Drop a file onto the app window or choose File > Open.

Do I need an internet connection?

The editor and cloning tools work offline. The AI agent and imports from NCBI or UniProt need an internet connection.

Which AI do I need?

You can use the Claude Code, Codex or Grok CLIs you already have, or an API key of your own. You can also use the editor and every cloning tool without AI.

Does the agent send my sequences anywhere?

Only to the AI provider you chose, and only when you ask the agent something.

Will it work on my Mac?

Yes. PlasmidLab supports both Apple silicon and Intel Macs. A Windows version is available too.

Where can I send a bug or an idea?

Email hello@plasmidlab.com, or report a problem or suggest a feature.
