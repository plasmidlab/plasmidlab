06

A FEW PRACTICAL DETAILS

Before
you start.

Do I need an internet connection?

The editor and cloning tools work offline. The AI agent and imports from NCBI or UniProt need an internet connection.

Which AI do I need?

Use the Claude Code, Codex or Grok CLIs you already have, or an API key of your own. The editor and all cloning tools also work without an AI connection.

Can I open my existing .dna files?

Yes. PlasmidLab reads and writes .dna, GenBank and FASTA files. Use File > Open, or drop a file on the window.

Does it run on my Mac?

PlasmidLab supports both Apple silicon and Intel Macs. A Windows desktop version is also available.

Does the agent send my sequences anywhere?

Only to the AI provider you choose, and only when you ask the agent something.

Where do I send a bug or a suggestion?

Email hello@plasmidlab.com, or report a problem or suggest a feature.
