The editor

A plasmid editor that behaves like a normal program.

Open a file with File > Open or drop it on the window. PlasmidLab reads and writes .dna, GenBank and FASTA, so the plasmids you already have open as they are.

Maps
Circular and linear, with features and restriction sites.
Sequence
Translations and features along the bases.
Enzymes
Restriction enzymes and enzyme sets.
Primers
A primer database, and PCR on the open sequence.
Gels and traces
Simulated gels, alignments, and .ab1 and .scf sequencing traces.
Analysis
Codon usage tables, a CRISPR guide window, feature detection, secondary structure.

A cloning plan is only as good as the sequences it was run on. The agent runs every digest, PCR and assembly on yours, and shows you each fragment, size and overhang before anything touches the bench.

How it works

Describe the construct. The agent works out the cloning.

  1. 1

    Describe it

    Type what you want in the panel, for example “Move the GFP from the pUC19 plasmid into the expression vector.” Work on your own plasmids, or start from one of six exercises.

  2. 2

    The agent designs it with the app’s own tools

    It runs real digests, PCRs and assemblies on your actual sequences, not a generic recipe, and writes the plan in the chat.

  3. 3

    The walkthrough plays

    An animated bench walkthrough of that specific design draws itself inside the app: digest, fragments, assembly, product, with the real enzyme names, sizes and overhangs.

Works with the Claude Code, Codex or Grok CLIs you already have, or an API key of your own. The editor and every cloning tool work without any of them.

When the plan is written, the agent draws an animated walkthrough of it and plays it inside PlasmidLab. Each step uses the names, sizes and overhangs from your sequences.

Cloning toolbox

Every method is a tool you can run yourself.

The agent uses the same tools you do. Open any of them from the editor and work by hand, with no AI involved.

  • Restriction cut and paste

    Move an insert with a digest and a ligation.

  • Gibson two piece assembly

    Join pieces by homology, with no scar.

  • Golden Gate

    Put a part into an acceptor in one reaction.

  • Gateway BP and LR

    An entry clone first, then an expression clone.

  • TA and TOPO cloning

    Take a PCR product into a vector.

  • Inverse PCR

    Amplify around the plasmid to delete or change it.

  • Overlap PCR

    Fuse fragments through overlapping primers.

  • Q5 site directed mutagenesis

    Change bases with designed primers.

  • Silent mutations

    Remove a site without changing an amino acid.

  • Ligating fragments

    Join digested pieces into one molecule.

  • Inserting fragments and features

    Place a sequence or an annotation at a position.

  • Alignments and traces

    Check a clone against its design and its .ab1 or .scf trace.

Questions

Before you download.

Do I need an internet connection?

No. PlasmidLab runs on your computer. Only the AI agent and imports from NCBI and UniProt need the internet.

Which AI do I need?

The agent works with the Claude Code, Codex or Grok CLIs you already have, or with an API key of your own. The editor and every cloning tool work without any of them.

Does the agent send my sequences anywhere?

Only to the AI provider you chose, and only when you ask it something.

Can I open my existing .dna files?

Yes. PlasmidLab reads and writes .dna files, GenBank and FASTA. Use File > Open or drop a file on the window.

Intel or Apple silicon?

Both. One Mac download runs on either.

Do I need a GitHub account?

No. The download buttons on this page take you straight to the installer.

Where do I send a bug?
