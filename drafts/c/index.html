Describe the construct. The agent designs the cloning and draws it out.

Write what you want in the panel the way you would explain it to a labmate. The agent works with PlasmidLab's own tools, so it runs real digests, PCRs and assemblies on the sequences you have open instead of reciting a generic recipe.

  1. You describe it

    Name the parts and the product you want. The sequences you have open are what it works on.

  2. It designs it with the app's tools

    It runs the digests, PCRs and assemblies itself and writes the plan in the chat, step by step.

  3. It draws the bench walkthrough

    Digest, fragments, assembly and product play out in the app, with the real enzyme names, sizes and overhangs.

Before you install

Does it need an internet connection?

No. Only the AI agent and imports from NCBI or UniProt go online.

Which AI do I need?

None for the editor or the cloning tools. For the agent, use the Claude Code, Codex or Grok CLI you already have, or an API key of your own.

Does the agent send my sequences anywhere?

Only to the AI provider you chose, and only when you ask it something.

Can I open my existing .dna files?

Yes. It reads and writes .dna, GenBank and FASTA files.

Mac with Intel or Apple silicon?

Both. There is a Windows version too.

Do I need a GitHub account to download it?

No. The download button gives you the installer file directly.
