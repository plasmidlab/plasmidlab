06 A few details

Before you
get started.

Do I need an internet connection?

The editor and cloning tools work offline. The AI agent and imports from NCBI or UniProt need an internet connection.

Which AI do I need?

The agent works with the Claude Code, Codex or Grok CLI you already have, or an API key of your own. You can use the editor and every cloning tool without connecting any AI.

Can I open my existing .dna files?

Yes. PlasmidLab reads and writes .dna files, GenBank and FASTA. Use File > Open, drop a file on the window, or double click a supported file after installation. Sequencing traces in .ab1 and .scf format also open in the editor.

Apple silicon or Intel?

Both. PlasmidLab runs on Macs with Apple silicon and Intel processors, and on Windows.

Does the agent send my sequences anywhere?

Only to the AI provider you choose, and only when you ask the agent something.

Where do I send a bug or a suggestion?

Email hello@plasmidlab.com, or report a problem or suggest a feature.
