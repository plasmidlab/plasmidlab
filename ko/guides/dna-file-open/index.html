.dna는 어떤 파일인가

.dna는 SnapGene®이 쓰는 파일 형식입니다. 서열뿐 아니라 기능(feature) 이름과 색, 프라이머, 원형·선형 구분까지 한 파일에 들어 있습니다. 그래서 메모장이나 TextEdit으로 열면 글자가 깨져 보입니다. FASTA로 바꿔 서열만 쓰면 지도 정보가 사라집니다.

1. PlasmidLab 설치하기

PlasmidLab은 Mac과 Windows에서 무료로 쓰는 플라스미드 에디터입니다. 아래 버튼으로 내려받아 설치합니다. 계정 없이 바로 쓸 수 있고 파일은 내 컴퓨터에 그대로 있습니다.

2. 파일 열기

File > Open…을 고르거나 창 위로 파일을 끌어다 놓습니다. 서열, 기능, 지도가 함께 열립니다. .dna 외에 GenBank(.gb, .gbk), FASTA, EMBL, 생어 시퀀싱 결과(.ab1, .scf)도 같은 방법으로 열립니다.

3. 지도와 제한효소 자리 보기

Map 탭에서 원형 지도를, Sequence 탭에서 서열을 봅니다. Analyze > Choose Enzymes…에서 보고 싶은 제한효소를 고릅니다. Analyze > Use Enzyme Set > 6 bp+ enzymes that cut once를 고르면 한 번만 자르는 효소만 지도에 남습니다.

4. 다른 형식으로 저장하기

File > Save As…에서 .dna, GenBank, FASTA 중에 고릅니다. SnapGene을 쓰는 동료에게는 .dna로, 분석 도구에 넣을 때는 GenBank나 FASTA로 보내면 됩니다.
