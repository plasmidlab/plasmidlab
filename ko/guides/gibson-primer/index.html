Gibson 어셈블리 프라이머 설계하는 법

Gibson Assembly®는 조각 끝이 서로 겹치기만 하면 제한효소 없이 이어 붙입니다. 설계에서 정할 것은 겹치는 구간을 어디에, 몇 bp로 둘지입니다.

프라이머는 두 부분으로 나뉩니다

각 프라이머는 3′쪽 어닐링 부위와 5′쪽 상동 꼬리로 이루어집니다. 어닐링 부위는 지금 증폭하는 조각에 붙고 상동 꼬리는 옆에 올 조각의 끝과 같은 서열입니다. 그래서 이웃한 두 조각은 같은 구간을 한 번씩 나눠 갖습니다.

상동 구간 길이

보통 15~25 bp로 잡고 20 bp 안팎을 많이 씁니다. GC가 아주 낮은 구간이면 조금 길게 잡습니다. 겹치는 구간에 반복 서열이나 다른 조각과 비슷한 서열이 들어가면 엉뚱한 조립이 생깁니다. 위치를 몇 bp 옮겨서 피하는 편이 낫습니다.

어닐링 온도는 꼬리를 빼고 정합니다

PCR 첫 두 사이클에서는 어닐링 부위만 주형에 붙습니다. 어닐링 온도는 꼬리를 뺀 3′ 부분의 Tm으로 정하세요. 전체 길이로 계산하면 온도가 너무 높게 나와 증폭이 안 됩니다. 프라이머 자체의 조건(길이 18~25 b, Tm 55~65 ℃, 3′ 끝은 G 또는 C)은 일반 PCR과 같습니다. 프라이머 설계 가이드에 자세히 적어 두었습니다.

벡터 선형화

벡터는 제한효소로 자르거나 역방향 PCR로 선형화합니다. 제한효소로 자를 때는 한 번만 자르는 효소를 씁니다. 자른 자리가 넣으려는 위치와 맞는지 확인합니다. 어느 쪽이든 잘린 벡터 양 끝과 인서트 끝이 상동 구간으로 겹쳐야 합니다.

PlasmidLab에서 설계하기

벡터와 인서트 파일을 File > Open으로 열고 Clone > Gibson Assembly®…를 고릅니다. 조각마다 원본 파일과 범위, 방향을 정합니다. 프라이머 탭에서 프라이머와 접합부를, 산물 탭에서 예상 산물을 확인합니다. 올리고를 주문하기 전에 접합부 서열과 코딩 부위의 리딩 프레임을 꼭 확인하세요. 설계는 실험 검증이 아닙니다.
