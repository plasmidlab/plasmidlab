.dna·GenBank 파일 열기

서열 파일을 여기에 놓으면 안에 든 내용을 보여줍니다. 파일에 적힌 이름, 길이, 원형인지 선형인지, 특징마다의 좌표, 그리고 그 좌표로 그린 플라스미드 지도입니다. 파일은 브라우저에서 읽고 어디로도 보내지 않습니다.

    이 페이지로 되는 일과 안 되는 일

    읽어서 보여 주기만 합니다. 고치지는 못합니다. 염기를 바꾸거나 특징을 추가하거나 파일을 다시 저장하는 기능은 없습니다. 지도 위의 두 버튼은 같은 서열을 GenBank나 FASTA로 다시 써 주고, 파일에 있던 특징을 그대로 담습니다.

    파일의 첫 번째 서열만 보여줍니다. GenBank나 FASTA 파일에는 서열이 여러 개 들어갈 수 있고, 그런 파일이면 몇 개가 있는지 알려 줍니다.

    시퀀싱 트레이스는 여기서 열지 못합니다. .ab1과 .scf 파일은 염기마다 형광 4채널을 담고 있어서 지도가 아니라 크로마토그램이 필요합니다. 이 페이지는 그런 파일을 받지 않고, PlasmidLab 앱이 엽니다.

    파일은 브라우저에 있는 파일 리더로 읽고 페이지 안에만 둡니다. 어디에도 올리지 않고, 만들 계정도 없습니다. 직접 확인해 볼 수 있습니다. 페이지를 열어 둔 뒤 네트워크를 끊어도 그대로 동작합니다.

    열 수 있는 파일

    읽는 코드는 PlasmidLab 앱이 쓰는 것과 같습니다. 여기서 열리는 파일은 앱에서도 열리고, 특징도 같은 좌표로 나옵니다.

    • .dna, SnapGene® 형식입니다. 바이너리 패킷, 특징·프라이머 XML, 노트까지 읽습니다.
    • GenBank(.gb, .gbk, .genbank)입니다. 여러 조각으로 나뉜 특징에 쓰는 join()과 complement() 표기도 읽습니다.
    • EMBL(.embl)입니다. 같은 GenBank 파서로 읽습니다.
    • FASTA(.fa, .fasta)입니다. 서열과 이름만 있고 특징은 없습니다.
    • 헤더가 있든 없든 염기만 적힌 .seq, .txt 파일입니다.

    지도를 그리는 방식

    원형 서열은 원으로, 선형 서열은 막대로 그립니다. 1번 위치는 원의 맨 위, 막대의 맨 왼쪽입니다. 특징은 좌표가 가리키는 자리에 그리고, 겹치는 특징은 안쪽 고리나 아래 줄로 내려서 서로 가리지 않게 합니다. 전체 길이의 0.5%보다 짧은 특징은 선보다 얇아지기 때문에 그 최소 너비로 그립니다. 이름은 해당 특징 옆에 붙이고, 다른 이름 위에 겹칠 자리밖에 없으면 생략합니다. 아래 표에는 모든 이름이 있습니다.
