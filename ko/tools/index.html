무료 DNA 도구

클로닝 전에 서열을 확인하는 도구 아홉 개입니다. 설치나 가입 없이 브라우저에서 바로 쓸 수 있습니다.

파일 열기

  • .dna·GenBank 파일 열기서열과 특징, 지도를 브라우저에서.

자르고 젤에서 확인하기

  • 제한효소 자리 찾기한 번, 두 번, 자르지 않는 효소까지.
  • 제한효소 목록인식 부위, 돌출과 호환되는 말단.
  • 가상 아가로스 젤절단했을 때 나올 밴드.

서열 읽기

  • DNA 번역과 ORF 찾기6개 프레임을 한 화면에, ORF 표시.
  • 역상보 서열 변환역순, 상보, 역상보를 한 번에.
  • GC 함량과 프라이머 Tm염기 개수, GC%, 프라이머 Tm.
  • 프라이머 다이머·헤어핀 확인셀프 다이머, 크로스 다이머, 헤어핀과 ΔG.

반응 준비하기

  • DNA 몰 농도·라이게이션 계산ng에서 pmol로, 인서트 양까지.

어떤 질문에 어떤 도구인가

  • 받은 .dna, GenBank 파일 안에 뭐가 들었나? .dna·GenBank 파일 열기
  • 이 두 효소가 내 플라스미드를 한 번씩만 자르나? 제한효소 자리 찾기
  • 이 효소는 어떤 말단을 남기고 저 효소 말단과 붙나? 제한효소 목록
  • 자르고 나면 젤이 어떻게 보이나? 가상 아가로스 젤
  • 인서트가 프레임에 맞나, 단백질은 어디서 시작하나? DNA 번역과 ORF 찾기
  • 리버스 프라이머 서열은 어떻게 쓰나? 역상보 서열 변환
  • 이 프라이머의 Tm과 GC 함량은? GC 함량과 프라이머 Tm
  • 이 프라이머가 자기들끼리 붙지는 않나? 프라이머 다이머·헤어핀 확인
  • 3:1로 라이게이션하려면 인서트를 몇 ng 넣나? DNA 몰 농도·라이게이션 계산

여기서 안 되는 일도 있습니다. 파일을 고치거나 시퀀싱 트레이스를 보거나 클로닝을 설계하는 것은 브라우저 도구가 아니라 앱이 합니다.

계산 방식

Tm, 단편 크기, 젤 밴드는 PlasmidLab 앱과 같은 코드로 계산합니다. 같은 서열을 넣으면 앱과 같은 값이 나옵니다. 제한효소 자리는 REBASE 목록으로 찾습니다. 붙여 넣은 서열은 브라우저 안에서만 처리하고 서버로 보내지 않습니다.
