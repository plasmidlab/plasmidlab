    번역, 프라이머, PCR, 피처 자동 인식을 지원합니다.

  • 검증

    서열 정렬, 가상 젤, 시퀀싱 트레이스, CRISPR 가이드를 확인합니다.

요청부터 산물까지, 단계마다 보여줍니다

AI가 에디터의 도구로 가상 절단, PCR, 조립을 실행합니다.

  • 1. 요청

    파일을 열고 무엇을 만들지 적습니다.

  • 2. 계획 확인

    반응마다 설계 내용이 함께 나옵니다.

  • 3. 진행 보기

    절단, 단편, 조립, 산물 순서로 재생됩니다.

자주 묻는 질문

인터넷 연결이 필요한가요?

에디터와 클로닝 도구는 오프라인에서도 쓸 수 있습니다. 인터넷은 AI 에이전트를 쓰거나 NCBI·Ensembl·Addgene 조회, BLAST 검색을 할 때만 필요합니다.

무료인가요?

앱은 무료입니다. AI는 10회까지 무료이고, 그다음엔 내 Claude·Codex·Grok 구독이나 API 키로 씁니다.

SnapGene®에서 만든 .dna 파일도 열리나요?

네. .dna, GenBank, FASTA 파일을 열고 저장할 수 있고 .ab1·.scf 시퀀싱 트레이스도 열립니다.

내 서열이 외부로 전송되나요?

AI를 쓰거나 BLAST 같은 온라인 검색을 직접 할 때만 보냅니다. AI 요청은 내가 고른 제공자에게만 가고, 무료 체험은 PlasmidLab 릴레이를 거쳐 Anthropic으로 갑니다. 자세한 내용은 개인정보처리방침에 있습니다. 무료 체험은 만 18세 이상만 쓸 수 있습니다.
