.dna는 어떤 파일인가요?

.dna는 바이너리 서열 파일입니다. 염기, 피처 정보, 프라이머, 플라스미드의 원형 여부를 텍스트 대신 압축된 형식으로 담습니다. 그래서 텍스트 에디터로 열면 읽을 수 없습니다. 이 형식을 읽는 프로그램이 필요하며, 확장자를 .txt나 .gb로 바꿔도 읽을 수 없습니다.

GenBank 파일과 같은 종류의 정보를 담으므로 .dna 파일을 GenBank로 바꿔도 피처가 남습니다. 서열 외의 정보도 보존하려면 염기만 저장하는 FASTA 대신 피처 정보를 담는 형식으로 보관하세요. 파일 가이드에서 PlasmidLab이 읽는 모든 형식을 확인할 수 있습니다.

자주 묻는 질문

SnapGene® 없이 .dna 파일을 어떻게 여나요?

PlasmidLab을 설치한 다음 File > Open을 고르거나 .dna 파일을 창에 끌어다 놓습니다. 서열, 지도, 피처가 함께 열려 바로 편집할 수 있습니다. 파일 열기 가이드에서 순서대로 안내합니다.

PlasmidLab은 무료인가요?

네. 앱은 무료로 내려받아 쓸 수 있습니다. AI 에이전트는 계정당 10회까지 무료이고, 그다음엔 내 Claude·ChatGPT·Grok 구독이나 API 키로 씁니다.

Mac과 Windows에서 쓸 수 있나요?

네. Mac 앱은 Apple silicon과 Intel에서 실행하며 Apple의 서명과 공증을 받았습니다. Windows용 설치 프로그램도 있습니다.

파일은 내 컴퓨터에 그대로 있나요?

네. 파일은 내 컴퓨터에서 열고 저장하며, 에디터와 클로닝 도구는 오프라인에서도 쓸 수 있습니다. 서열은 AI 에이전트를 쓰거나 NCBI BLAST(Analyze > Search NCBI) 같은 온라인 검색을 직접 시작할 때만 외부로 보냅니다. 에이전트는 내가 고른 제공자에게만 서열을 보내며, 무료 체험은 PlasmidLab 릴레이를 거쳐 Anthropic으로 보냅니다. 개인정보처리방침을 확인하세요.

.dna 파일을 GenBank로 어떻게 바꾸나요?

PlasmidLab에서 .dna 파일을 연 다음 File > Save As에서 GenBank를 고릅니다. 피처, 프라이머, 원형·선형 구분을 GenBank 파일에 기록하므로, 파일을 담는 형식만 바뀌고 내용은 그대로 남습니다. 반대로도 바꿀 수 있고, 서열만 필요한 프로그램에는 FASTA로 저장하면 됩니다.

.dna 파일을 편집할 수 있나요, 아니면 보기만 가능한가요?

편집할 수 있습니다. PlasmidLab에서 파일을 열어 염기를 바꾸고, 피처를 추가하거나 옮기고, 프라이머를 설계하고, 가상 클로닝을 실행한 다음 .dna, GenBank, FASTA로 저장할 수 있습니다.
